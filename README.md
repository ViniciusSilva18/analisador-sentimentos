**Análise de sentimentos de avaliações e textos via Gemini LLM com interface web premium.**

## ✨ Funcionalidades
- 🟢 Classificação: Positivo, Negativo, Neutro, Misto
- 📊 Percentagem de confiança com barra visual
- 🏷️ Extração de palavras-chave
- 🌐 Interface web incluída

## 🛠️ Setup
```bash
pip install -r requirements.txt
cp .env.example .env
python app.py  # Aceda: http://localhost:5000
```
